# Disaster Relief Resources Allocation Management Information System

### 📌 Project Overview
This Management Information System (MIS) was developed as an academic requirement to streamline, automate, and optimize the allocation of critical resources (such as medical supplies, food, water, and personnel) during emergency disaster relief operations. The system ensures data-driven decision-making, minimizing delays when distributing aid to affected regions.

### 🛠️ Key Features
* *Resource Tracking:* Real-time monitoring of available inventory and logistics supply chains.
* *Allocation Optimization:* Structured routing of supplies based on priority and urgency levels of affected zones.
* *Database Management:* Structured storage of emergency contact data, resource categories, and distribution logs.
